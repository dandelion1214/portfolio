## 📖 关于本项目

这是王楚杰的个人作品集网站，展示了在AI内容运营领域的实战经验和自研工具。

### 🌟 核心亮点

- **账号运营案例**：从0到1，从1到10的实战经验
  - 史上醉：单期最高点赞100万+，20+爆款视频
  - GM的秘密基地：单期最高播放283万，涨粉300万+
  - 超级嘎嘎：首月曝光1500万，月涨粉10万+

- **内容创意系列**：爆款内容系列的创意与迭代
  - 自孵化系列：地图系列首发226万赞，后续均赞80万+
  - 供应商系列：伤感文学系列均赞10万+，数据排名前10%

- **内容基本功**：封面设计与文案创作能力
  - 封面设计：20+案例，从素材筛选到成品输出
  - 文案创作：5条文案认知，完整对比案例

- **自研AI工具**：智能化内容生成工具
  - 开头方案生成工具：200+爆款案例库支撑
  - 自动化选题库工具：12+选题分析维度
  - 热点灵感涌现工具：可无限复用的选题库

5. 等待部署完成
